# Derivation lessons (offline)

Builds the scrolling "derivation" lesson format from a JSON spec. No API calls.

    node scripts/derivation/build.js specs/economics_scarcity.json specs/economics_scarcity.html
    node scripts/derivation/preview_layout.js specs/economics_scarcity.json layout.html   # graph layouts only

## Spec

    { id, subject, title, terms: { key: { label, colour? } }, widgets?: ['econ_ppf'],
      stages: [ { name, title, sub, given: [terms already on the map], builds, edges: [[from, to]],
                  layout?: { term: [col, row] },   // only when auto-layout is too wide
                  steps: [ read | ask | order | chains | derive ] } ] }

- `read`   `{ term, text }`: text ends where the term name goes.
- `ask`    `{ q, right, wrong, hint, pre, term, fig? }`: answering it introduces `term`. Option order is shuffled at runtime.
- `order`  `{ terms, prompt }` and `chains` `{ lanes: [{ label, terms }], prompt, then? }`: milestones after at most 4 new terms.
- `derive`: final test; its prompt, bridge and the title slide are generated.

## Rules enforced by the builder
Never more than 4 new terms between milestones; every term introduced exactly once; a milestone covers exactly the terms
introduced since the last one; milestone prompts start "Drag and drop the N key terms"; edges only between terms of that stage;
`given` terms must come from an earlier stage; every term has an edge; each stage ends in a derive.

Not automated yet: writing the read/ask steps for a node (done by hand here, to be generated by a prompt and then validated).

## Whole-map pipeline
    node plan_stages.js ../knowledge_map_economics_alevel.json plan.json   # 1243 nodes -> 193 stages, one node = one term
    node estimate_cost.js ../knowledge_map_economics_alevel.json           # token and dollar estimate, no API calls
    ANTHROPIC_API_KEY=... node generate.js <map.json> <out-dir> --limit 6          # spends money; one at a time
    ANTHROPIC_API_KEY=... node generate.js <map.json> <out-dir> --batch            # Batch API, half price; add --resume <id> to rejoin a batch

Extra rules the validator learned while the two sample stages were checked by hand: a question or either option may not
contain the term it is about to reveal; right and wrong options must be similar in length (the approved artifact had a
17-character wrong answer against a 50-character right one); terms must be taught after their prerequisites.
`given` shows at most 5 terms; the full prerequisite list goes in `needs` for the schedule.
